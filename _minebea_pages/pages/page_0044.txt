Chapter5 Various Operation Methods
5.3 Position Management Settings
Set the parameter by writing the value to a given address.
See below for how to set it up.
When using a dedicated application, see the manual of the dedicated application.
When using RS485 communications, see ➡8 RS485 Communication.
Turn on the control power supply to set the position management parameters.
To rewrite the following parameters, a power cycle is required. When the value of the parameter
is written, a power cycle alarm (alarm 15) is issued. When the control power is turned on again,
the alarm disappears and the written value is reflected. If there is no problem with the initial
value, this setting is not necessary.
 Setting the Resolution

revolution.
