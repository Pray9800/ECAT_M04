The operating speed in each mode is determined by the program operation base
acceleration/deceleration (81EH) x deceleration rate.
For example, to set the operating deceleration of Mode 6: Relative position
control/(encoder position reference) to 800000 [pps/s],
- program operation base acceleration/deceleration (81EH) = 800000 [pps/s],
deceleration rate = 100 (%),
- program operation base acceleration/deceleration (81EH) = 1600000 [pps/s],
deceleration rate = 50 (%).
 Coupling
In step transition, if you want to select "Coupling" to transition to the next step
without stopping the motor, set this to 1. If not, set this to 0.
 Loop Position Offset
Sets the offset value to be added to the target position each time the loop is
repeated.
 Wait time
Set the waiting time after the end of the move.
 Next Operation Data Number
Set the next power transfer data number to be executed after completion. Set it to -1
for exit.
