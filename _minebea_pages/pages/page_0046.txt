 Setting the Limit Switch
Install external switches/sensors at the end of the movable range and configure limit
switches to stop movement for safety.
If the movable range is not restricted, no configuration is necessary. This can also be
replaced with the software limit described later.
① Assign limit switches LS+ and LS- to IO control inputs.
Refer to ➡6.2.1 IO Control input for the setting method.
The set values are LS-FWD (28) for LS+ and LS-REV (29) for LS-.
② Set the enable levels for limit switches LS+ and LS- (Parameters 051BH, 051CH).
③ Set the stop method when limit switches LS+ and LS- are active (Parameter 051DH).
Alarm 10 (Out of Position Range) can also be triggered (Set value 3).
