6.2.2 Virtual Connection Input
A virtual connection input (VI) is a method of inputting an output signal set to a virtual
input source to an input signal set in the input function of a virtual connection input.
Output and input signals can be connected without wiring, and up to four can be set.
name explanation
Input Functions Select the signal that you want to assign to the VI.
Signal Source Selection Select the output signal that you want to use as input for the VI.
Invert settings The signal polarity can be reversed.
