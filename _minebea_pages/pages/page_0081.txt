Chapter6 Control signal
No. parameter explanation
50～51 reservation Not used
52 INCH-FWD Executes inching in the (+) direction.
The inching travel distance is set with parameter 0820H, and the
speed with 081CH.
This function can not be executed when external pulse commands
are enabled (0514H:0).
53 INCH-REV Executes inching in the (-) direction.
The inching travel distance is set with parameter 0820H, and the
speed with 081CH.
This function can not be executed when external pulse commands
are enabled (0514H:0).
54～55 reservation Not used
56 POS-FWD Executes position control operation in the (+) direction.
The motor is driven at the speed of the operation data number
selected by PNUM0 to PNUM5, only while the signal is ON.
This function can not be executed when external pulse commands
are enabled (0514H:0).
57 POS-REV Executes position control operation in the (-) direction.
The motor is driven at the speed of the operation data number
selected by PNUM0 to PNUM5, only while the signal is ON.
This function can not be executed when external pulse commands
are enabled (0514H:0).
58 SPD-FWD Executes speed control operation in the (+) direction.
The motor is driven at the speed of the operation data number
selected by PNUM0 to PNUM5, only while the signal is ON.
This function can not be executed when external pulse commands
are enabled (0514H:0).
59 SPD-REV Executes speed control operation in the (-) direction.
The motor is driven at the speed of the operation data number
selected by PNUM0 to PNUM5, only while the signal is ON.
This function can not be executed when external pulse commands
are enabled (0514H:0).
60 PSH-FWD Executes torque control operation in the (+) direction.
The motor is driven with the speed and torque of the operation
data number selected by PNUM0 to PNUM5, only while the signal is
ON.
This function can not be executed when external pulse commands
are enabled (0514H:0).
61 PSH-REV Executes torque control operation in the (-) direction.
The motor is driven with the speed and torque of the operation
data number selected by PNUM0 to PNUM5, only while the signal is
ON.
This function can not be executed when external pulse commands
are enabled (0514H:0).
