 Setting the Software Limit
Configure the software limit settings to restrict the movable range using software only,
without external switches or sensors. No configuration is necessary if you do not wish
to restrict the movable range.
① Set the software limit position (+ side) and software limit position (- side).
Set these using signed 31-bit positions. Rounding is not supported.
Set the position after resolution change via electro gear.
② Set the stop method when the software limit (+ side) and softwawre limit (- side) are
active (Parameter 0523H).
Alarm 10 (Out of Position Range) can also be triggered (Setting Value 3).
