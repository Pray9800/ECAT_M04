8.2 Communication Overview
This unit communicates via Modbus Protocol.
The transmission mode corresponds to RTU mode (binary method).
item RTU Mode
protocol MODBUS RTU
Synchronization method Half-duplex, asynchronous
Start Bit 1 bit
Data Length 8-bit
Parity Bit None
Stop Bits 1 bit
Communication Codes Binary code
Start Character None
End Character None
False Detection Cyclic redundancy check: CRC-16
