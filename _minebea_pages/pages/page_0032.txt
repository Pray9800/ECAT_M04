( 4 ) Timing chart for pulse input method
 2-pulse input method (parameter 0115H is 0: P1=CW, P2=CCW)
The direction of rotation is determined by whether pulses are input to P1 or P2.
 1-pulse input method (parameter 0115H is 1: P1=pulse, P2=direction)
When a pulse is input to P1, the direction of rotation is determined by whether P2 is
at a HIGH or LOW level.
 Phase difference input method (parameter 0115H is 2: P1 = phase A, P2 = phase B)
The direction of rotation is determined by inputting pulses that are 90° out of phase
between phase A and phase B, and which phase is more advanced.
