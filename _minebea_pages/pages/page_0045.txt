➡ 9.5.1 Common Parameters
 Setting the Round Position
Sets the round position setting to repeatedly count the position with the set number of
rotations.
It is used when rotating and returning to the original position, such as a turntable.
If you only use the normal position (counted in signed 31 bits), you do not need to set
it.
