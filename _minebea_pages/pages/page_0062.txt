Chapter5 Various Operation Methods
( 2 ) JOG
JOG operation that can be stopped at any timing using the input signals JOG-FWD/JOG-REV.
①Turn on the main power supply and control power supply.
②Check that the READY output (ready for operation) is ON and the SV-STS output (servo
on state) is ON. ※1 ※2
③urn ON the JOG-FWD or JOG-REV input; when the JOG-FWD input is turned ON, the motor
rotates in the (+) direction; when the JOG-REV input is turned ON, the motor rotates
in the (-) direction. READY output is OFF and the MOVE output is ON
④At the timing when you want to stop the motor, turn OFF the JOG-FWD input or JOG-REV
input that was turned ON in step ③. The motor starts decelerating.
⑤The motor stops, the READY output is ON, and the MOVE output is OFF.
※1 If there is a difference in the signal condition, see ➡5.4.7 Status check.
※2 This chart shows the automatic servo on enabled when the control power is turned on (parameter
0516H: 0 (initial value)). If automatic servo on disabled (parameter 0516H: 1), execute servo-
on. For servo-on, refer to ➡5.4.5 Other operation:Servo On (Automatic Servo On is disabled).
