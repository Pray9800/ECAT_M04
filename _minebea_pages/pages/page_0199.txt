( 3 ) Sub-notification List
A sub-notification is output when an action request fails. Sub-notifications are output when
the function is enabled (the default value is disabled).
item content
Command execution This is output when an action request is not executed.
failure
Illegal target value This is output when an action request is made that includes an inappropriate
target value.
( 4 ) Notification History
Up to 16 notifications are saved in order from the most recent to the most recent, and the
notification history saved can be retrieved or deleted by one of the following methods.
- Network communication
- Dedicated application
Notifications are not stored in non-volatile memory and are erased when the power is turned
off.
