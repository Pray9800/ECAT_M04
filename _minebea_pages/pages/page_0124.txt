( 3 ) Coupling operation
In program operation, the operation mode can be set to relative positioning (coupling
operation) or absolute positioning (coupling operation) to perform coupling operations. The
coupling motion allows you to connect that step to the next, allowing you to change speed
or torque during movement.
 When coupling, set the following steps in addition to the operation mode. If there is
no setting for the next step, the coupling operation will not occur.
 When coupling, set both the operation mode of the step and the next step to the
coupling operation.
 The wait time of the coupling steps is no longer valid.
