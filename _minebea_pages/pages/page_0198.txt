10.2 Notification
Notification output can be made before an alarm occurs.
Each notification value can be set appropriately to help maintain the equipment.
You can check the type of notification that is occurring from various communication I/Fs, control
output, and dedicated applications. When a notification occurs, the ALM LED flashes every two
seconds. If an alarm occurs at the same time, the ALM LED will give priority to the alarm display.
When a notification occurs, the motor continues to run without stopping.
( 1 ) Clear Notification
Once you have eliminated the cause of the notification, clear the notification in one of the
following ways:
- Clearing notifications from network communication
- Notification clearing from control signals
- Notification clear from the dedicated application
If the automatic clearing of notifications is set, it will be automatically cleared when the
cause of the notification is removed.
( 2 ) Notification List
Notifications are output when the threshold is exceeded. The types of notifications, the
threshold ranges, and the initial values are shown in the table below.
