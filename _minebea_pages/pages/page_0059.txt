Chapter5 Various Operation Methods
( 2 ) Operation
Position control is performed by pulse input.
①Turn on the main power supply and control power supply.
②Make sure that the SV-STS output (servo on state) is ON. ※1 ※2
③When the pulse is input, the motor rotates, and when the input is finished, the motor
stops.
④After the pulse input is completed, check that the INPOS output is ON and the operation
is terminated. ※3※4
※1 If there is a difference in the signal condition, see ➡5.4.7 Status check.
※2 This chart shows the automatic servo on enabled when the control power is turned on (parameter
0516H: 0 (initial value)). If automatic servo on disabled (parameter 0516H: 1), execute servo-
on. For servo-on, refer to ➡5.4.5 Other operation:Servo On (Automatic Servo On is disabled).
※3 During motor operation by pulse input, the INPOS output may be turned on. In principle, it is
more likely to occur when the motor operation is slow or when it follows the pulse input well.
After all pulse inputs are completed, the operation is judged to be complete when the INPOS
output is turned on.
※4 The INPOS output is turned on when the motor position (encoder position) is within a
predetermined distance from the target position. The above distance can be adjusted by the
parameter 010AH (imposition zone count value). Set it according to your needs.
