9.5 Parameter setting
Accessing the internal registers allows the user to set the parameters of motor controller.
For details on how to access the internal registers, see ➡8 RS485 Communication.
The "Reflect" column in each table indicates the timing when the operation command is reflected.
For more information, see➡ 9.2 Reflection timing setting parameters.
