・ About the type of Operation Order
The differences between the types of position control are as follows:
6: Relative position control(encoder position base)
Set the target position (3006H, 3007H) with a relative value based on current encoder
position.
7: Absolute position control
Set the target position (3006H, 3007H) with absolute position.
16: Relative position control/force(encoder position base)
Set the target position (3006H, 3007H) with a relative value based on current encoder
position, and force control operation is performed.
17: Absolute position control/force
Set the target position (3006H, 3007H) with absolute position, and force control
operation is performed.
